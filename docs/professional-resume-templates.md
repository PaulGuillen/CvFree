# Professional resume templates

Research reviewed on 2026-11-15:

- [Harvard: Create a Strong Resume](https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/): consistent formatting, clear organization and checking the PDF result.
- [CareerOneStop: Formatting](https://cloudfront.careeronestop.org/JobSearch/Resumes/ResumeGuide/formatting.aspx): restrained typography and a detailed work history.
- [University of Pennsylvania: Write a Resume/CV](https://careerservices.upenn.edu/channels/resume/): decorative formatting and images can cause problems for applicant tracking systems.

These original layouts apply those principles without copying university templates or implying endorsement:

| Template | Presentation | Suggested use |
| --- | --- | --- |
| Cambridge | Centered serif name, monochrome section rules | Traditional professional applications |
| Berlin | Stacked bold name opposite contact, section labels in a left rail and content on the right | Technical and chronological resumes |
| Vienna | Serif name opposite contact details, balanced columns with a vertical rule | Editorial professional profiles |
| Oslo | Large centered sans-serif name, narrow qualifications column, wider career column | Compact profiles emphasizing experience |
| Lima | Bold centered sans-serif name and contact, centered section headings, horizontal rules and vertical experience guides | Traditional single-column professional profiles |

Cambridge is retained; London and Zurich have been removed from the catalog. The three new original layouts take structural inspiration from [Jake's Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs), [Omkar Prabhu's Resume Template](https://www.overleaf.com/latex/templates/resume-template/gxymbfbhdjwk) and [Deedy CV](https://www.overleaf.com/latex/templates/deedy-cv/bjryvfsjdyxz). Their source code and sample content are not copied. All new layouts are monochrome.

All layouts retain textual language levels, wrapping links, rich text and optional section visibility. Vienna places summary above career history on the left, followed by references; qualifications, skills, languages, courses and links occupy the right column. Oslo puts education, links and languages in a narrower left column; summary, experience, skills, courses and references occupy the right column, with skills above courses. Empty groups render no headings. Older documents referring to removed templates continue to use the existing catalog fallback.

Lima adapts the visual structure of the user-provided Word reference. No personal details, employment history, or document assets from that reference are bundled in the application. Its preview uses the existing fictional sample. Links have an explicit localized section heading in Cambridge, Berlin, Vienna, Oslo, Lima and Tokyo, shown only when enabled and nonempty.

The PDF exporter embeds rendered bitmaps. These additions do not make exported PDFs searchable or guarantee ATS compatibility. A separate text-based PDF export implementation is required for selectable text and reliable automated extraction. The download dialog offers A4 pages with 24-point outer margins (default) or a continuous page. In A4 mode, long previews are split near rows with fewer color transitions to favor spaces between text lines, including templates with solid sidebars. This visual heuristic does not guarantee keeping whole paragraphs or section headings together, especially when adjacent columns have different line positions.

Lima starts with the summary and ends with links after references. Cambridge places links immediately before references.
